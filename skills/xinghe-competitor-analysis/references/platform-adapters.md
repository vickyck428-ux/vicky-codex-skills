# 电商平台适配

## 目录

- 通用要求

- 跨境平台
- 未知平台

## 通用要求

先使用链接解析脚本识别平台、商品ID、变体和追踪参数，再在浏览器中确认页面实际内容。平台字段可能随版本变化；以当前可见页面为准，不依赖固定选择器作为唯一来源。

## 国内平台

| 平台 | 常见域名 | 重点字段 | 常见限制 |
|---|---|---|---|
| 淘宝/天猫 | `item.taobao.com`、`detail.tmall.com` | SKU、券后价、月销、问大家、详情长图、店铺类型 | 登录墙、地区价、动态接口 |
| 京东 | `item.jd.com`、`item.m.jd.com` | 京东价、SKU矩阵、榜单、店铺/自营、配送、服务承诺 | 价格/评论接口可能受限 |
| 拼多多 | `yangkeduo.com`、`pinduoduo.com` | 拼单价、单买价、已拼、SKU、百亿补贴、退换保障 | 移动端/登录、短链跳转 |
| 抖音商城 | `jinritemai.com`、`douyin.com` | 直播/达人关联、券、销量、店铺体验、商品素材 | 登录、App内页、短链 |
| 快手小店 | `kwaishop.com`、`kuaishou.com` | 商品价、销量、达人/直播关联、店铺与售后 | 登录、App内页、短链 |
| 小红书商城 | `xiaohongshu.com` | 商品规格、买手/笔记关联、价格、销量和评价 | 登录、App内页、地区与活动价 |
| 1688 | `detail.1688.com` | 阶梯价、起订量、混批、规格、供应商、复购/回头率 | 登录、批发单位复杂 |

对平台店铺首页不做店铺级分析；遇到店铺链接，请用户提供具体商品页。

## 跨境平台

| 平台 | 重点字段 | 特别处理 |
|---|---|---|
| Amazon | ASIN、站点、Buy Box、价格/优惠券、变体、卖家、FBA/FBM、评分、五点、A+ | 固定国家/地区和配送地址；区分父子ASIN、订阅价与一次性购买价 |
| TikTok Shop | 商品ID、区域站、价格、销量、达人/视频素材、卖家与履约 | 页面常需登录或App；记录地区与货币 |
| AliExpress | 商品ID、价格区间、Choice、优惠、变体、订单、评分、配送 | 区分新客价、跨店券、税费和目的地运费 |
| Temu | 商品ID、活动价、划线价、销量/评价、规格、配送与退货 | 价格高度个性化；记录地区和会话 |
| eBay | Item ID、成色、竞拍/一口价、卖家评分、运费、退货 | 二手/翻新必须单列，不能与新品直接比价 |
| Walmart | Product ID、卖家、配送/自提、变体、评分、订阅/会员权益 | 区分Walmart销售与第三方卖家 |
| Shopee/Lazada | 国家站、活动价、券、已售、评分、变体、店铺、跨境配送 | 固定国家站、币种和活动时段 |
| Shopify/DTC | 产品Handle、变体、价格、订阅、评论、运输、退货、页面结构 | 自定义域名无法仅凭URL确认Shopify；通过页面元数据识别 |

## 未知平台

对未知商品页使用通用适配：

1. 从结构化数据（JSON-LD/OpenGraph）、可见正文和图片识别商品。
2. 寻找价格、货币、变体、库存、评分、评论、卖家、配送和退货。
3. 若无法确认是商品页，转为品牌官网模式；若是市场店铺页，说明不支持并索取商品链接。
4. 不宣称支持绕过登录、地区限制、验证码或付费数据。
