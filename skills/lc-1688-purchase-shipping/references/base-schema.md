# 飞书采购发货主账

## 默认目标

- Base：`1688采购与发货总表`
- URL：`https://my.feishu.cn/base/RQVSbSMusaNYlbsy5oxcgFHon3m`
- 数据表：`采购发货明细`
- 唯一业务键：`明细ID`

不要硬编码字段 ID、视图 ID 或运行时解析出的 token。每次正式写入前，通过 URL 和表名实时读取结构。

## 字段语义

### 识别与来源

- `商品主图`：附件，必填，放在前两列并显示缩略图。
- `商品名称`：文本，必填。
- `规格/SKU`：文本，必填，每种颜色、款式、尺寸独立一行。
- `明细ID`：文本，必填且唯一，用于幂等更新。
- `采购批次`：文本，必填。
- `1688订单号`：文本，可空。
- `下单日期`：日期，可空。
- `供应商`：文本，必填。
- `源订单截图`：附件，必填。
- `采购状态`：单选，必填。

### 收货

- `订购数`：数字，正整数，必填。
- `已核对收货`：复选框。
- `实收数`：数字。
- `到货日期`：日期。
- `到货实拍`：附件。

### 分配

- `去向`：单选，`待定` / `Amazon` / `Walmart` / `拆分`。
- `Amazon拆分数`、`Walmart拆分数`：数字，仅拆分时填写。
- `Amazon计划数`、`Walmart计划数`：公式，只读。

### 发货

- `Amazon已发数`、`Walmart已发数`：数字。
- `Amazon待发数`、`Walmart待发数`：公式，只读。
- `最后发货日期`：日期。

### 管理

- `图片状态`、`数量校验`、`总状态`：公式，只读。
- `实物标签码`：公式或文本，按当前表结构只读处理，禁止覆盖现有公式。
- `Amazon SKU`、`Walmart SKU`、`备注`：文本。

## 采购状态

允许值：

- `待付款`
- `待发货`
- `已发货`
- `运输中`
- `待取件`
- `待收货`
- `已签收`
- `已取消`

待付款商品默认写入，不因尚未付款而排除。

## 固定视图

- `00 待付款`
- `01 缺少商品图`
- `02 待收货`
- `03 数量异常`
- `04 待分配`
- `05 Amazon待发`
- `06 Walmart待发`
- `07 已完成`
- `08 全部明细`

所有视图应固定显示商品图片、商品名称、规格和数量。正式写入后检查视图命中，不在导入时擅自重建筛选条件。

## 写入规则

1. 读取实时字段结构并按字段名匹配。
2. 读取所有目标 `明细ID`；同一 ID 命中多行时停止。
3. 先写可编辑字段，跳过公式字段。
4. 再上传 `商品主图` 和 `源订单截图`。
5. 附件操作失败时先读回目标单元格；只有确认目标文件未出现才能重试。
6. 缺字段、字段类型不符或单选项缺失时停止正式写入，生成结构变更预览并重新请求确认。

## 写后验收

- 清单行数 = Base 命中行数。
- 清单总件数 = `订购数` 合计。
- `明细ID` 无空值、无重复。
- 每行 `商品主图` 和 `源订单截图` 至少各 1 个附件。
- `待付款` 行数和件数与清单汇总一致，并进入 `00 待付款`。
- `01 缺少商品图` 和 `03 数量异常` 仅出现真实异常。
- 重复导入 dry-run 的计划结果为全部更新、零新增。
