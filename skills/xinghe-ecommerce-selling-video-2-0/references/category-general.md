# 通用兜底模板

适用：无法明确归类的产品。

15 秒结构：

```text
0-2s：一句话痛点或好奇钩子
2-5s：产品外观和核心用途
5-8s：真实使用动作
8-10s：材质/结构/细节证明
10-13s：使用场景或前后对比
13-15s：适合人群 + CTA
```

口播公式：

```text
这个[产品]，解决的是[痛点]。
[核心卖点 1]，用起来[体验]。
[核心卖点 2]，[场景]也很适合。
细节上[材质/结构/设计]，看得出质感。
需要[目标结果]的，可以直接试试。
```

## 带货强化

- 首秒钩子：一句话痛点、好奇点或使用结果。
- 动作演示：真实拿取、打开、安装、使用、对比。
- 证明镜头：材质、结构、细节、包装、前后变化。
- 场景镜头：选择最接近用户购买场景的空间。
- 风险词：不要虚构价格、认证、排名、材质、功效。
- 默认 CTA：有这个需求的可以看看。
