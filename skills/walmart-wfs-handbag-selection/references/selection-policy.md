# 选品与缺口判定规则

## 1. 双池与关键词

- `MAINSTREAM`：明确面向女性的 handbag/purse，包括肩包、斜挎包、hobo、tote、satchel、clutch、top-handle、baguette、bucket 和 wristlet。
- `STYLE`：仍必须是明确的女式 handbag/purse，只在此基础上叠加 Y2K、金属、牛仔、蝴蝶结、异形、gothic、lolita、coquette、crochet、concert、ita、pins display 等风格或场景。
- 正式关键词总数60–80个，每池至少30个；当前模板为40+40。
- 每个工作日取主流2词、风格2词。优先从未成功运行的词；所有合格词至少运行一次后才允许重跑；同词冷却28天。
- 泛词标记 `BENCHMARK`，每词2–3页，候选不超过当日20%。特色长尾词承担约80%发现资源，默认每词5页。
- 完成25个 Walmart 核验后输出早期建议；至少50个样本后才调整池比例和页面深度。
- 关键词不强制包含 `purse` 或 `handbag`。`shoulder bag`、`crossbody bag`、`tote bag`、`concert bag`、`ita bag`、`pins display bag` 等明确女包包型或场景均可；只有完全无法证明包型的泛化 `bag` 才进入待复核。
- 背包、rucksack、bookbag、电脑包、briefcase、午餐包、保温包、旅行袋、行李、收纳袋、化妆包、健身包和尿布包不属于本流程。

## 2. Amazon 门禁

- 售价至少25美元。
- Parent ASIN 30天销量150–600，具体子体/颜色30天销量必须大于0。
- 价格、评论、Parent 30天销量和子体30天销量在技术试跑中的字段覆盖率不得低于80%。
- 这组核心门槛只可提出修改建议，不得由脚本自动调整。
- 关键词进入正式池前必须有搜索量、90天趋势、CPC、转化率、购买量、SPR、标题密度、Top3购买占比、均价和平均评论数等验证数据。

## 3. 历史去重

- ASIN 全历史硬去重；相同 ASIN 的来源关键词、首次/末次发现时间和出现次数合并。
- 相同 Parent ASIN 归为一个独立商品组。
- 不同 ASIN 若标准化品牌+标题或图片高度相似，归入同一商品组并标记 `POSSIBLE_DUPLICATE`，不自动删除。
- 独立商品组是新增商品和机会数量的统计单位，颜色、尺寸和重复 ASIN 不得重复计数。
- 旧商品只有价格变化≥10%、销量变化≥20%、跨越150/600门槛或 Walmart 状态变化时才重新进入日报。

## 4. Walmart 缺口状态

- `INITIAL_GAP`：关键词和主要替代词搜索后，没有明显相同或高度重合商品，可进入初始候选。
- `STRONG_GAP`：没有明显同款，且有 Assortment Growth、Search Insights 或图片证据。
- `WEAK_SUPPLY`：只有1–3个接近商品，或价格、配送、评价、WFS供给较弱。
- `NEEDS_REVIEW`：暂未发现明显同款，但关键词、替代词、类目或图片证据不完整。
- `SUPPLY_DENSE`：明确同款或高度相似供给密集，降级或淘汰。

额外证据只升级优先级，不阻止商品进入 `INITIAL_GAP`。美国和加拿大必须分别搜索和记录。

## 5. 报告与机会

日报分别显示初步缺口、强缺口、弱供给、待复核、历史重复、疑似同款、新增独立商品、已确认机会、阻塞原因和报告哈希。

- 每日目标是至少发现5个“没有明显重合”的初步机会。
- “已确认机会”必须完成需求、供应链、利润和 IP 门禁；不得用初步缺口冒充。
- 只报告新增或关键变化。零新增时只回报运行词数、新增数、关键变化和历史重复数。
- 报告哈希与日期、报告类型共同形成投递幂等键。

## 6. 每日30款分流

- 正式日跑保存30个独立产品组，`MAINSTREAM` 15款、`STYLE` 15款。
- 30款必须完成沃FBM基础门禁并全部保留为FBM候选；不自动发布。
- 最多4款额外进入沃美WFS优先候选，两个美国店各最多2款，每款T1 1件。
- `INITIAL_GAP`、资料不全或利润不足的商品不能直发WFS。
- WFS选择与沃FBM有效首单转WFS分开统计，后者采购优先级更高。
- 加拿大当前只保留FBM路线并独立核验需求，不能照搬美国WFS信号。

## 7. 安全边界

全流程只生成候选和建议，不创建 Listing、不采购、不发 WFS、不修改平台商品状态。任何登录、验证码、字段缺失或中断均整批 `BLOCKED`。
