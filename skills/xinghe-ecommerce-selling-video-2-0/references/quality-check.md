# 成片质检清单

生成后默认从以下角度复盘：

1. 商品一致性：颜色、形状、结构、Logo、包装是否变了。
2. 动态质量：是否只是图片缩放，是否有真实动作或使用过程。
3. 带货节奏：0-2 秒是否有钩子，13-15 秒是否有 CTA。
4. 卖点视觉化：卖点是否通过动作/特写/对比表达出来。
5. 口播：是否有中文口播，是否贴合产品，是否自然。
6. 字幕文字：用户未要求字幕时，是否出现乱码或多余文字。
7. 画面构图：产品是否居中，是否被裁切，是否有无关元素抢戏。
8. 时长分配：细节特写是否过长，主产品展示是否足够。
9. 合规风险：是否夸大功效、出现不适合的人脸/儿童/危险动作。
10. 转化力：是否让用户知道为什么买、适合谁、现在怎么行动。
11. 平台适配：比例、口播、CTA、文字层是否匹配目标平台。
12. 分镜门禁：是否已生成 `storyboard.json`、`storyboard.md` 和 `storyboard_sheet.png`，且分镜图已随产品图一起提交。
12.1. 生图优先级：`storyboard_sheet.png` 是否优先通过 `scripts/generate_storyboard_image.py`、本地 helper 或 HTTP API 生成；只有这些路径失败时才使用内置 `image_gen` 兜底。
13. 非复刻边界：是否没有下载/抽帧/ASR/OCR/blueprint/逐镜头还原参考视频。
14. 文字层冲突：有口播时是否避免逐句字幕和贴纸双层重复。
15. 真人带货感：是否有真人主播、模特、手模或画外音配真实使用场景，而不是纯静物旋转。
16. 必拍结果画面：服装是否上身，床品是否铺床，收纳/清洁是否前后对比，食品是否有感官结果，美妆是否有质地/使用后状态。
17. 商品身份锁：颜色、形状、尺寸比例、包装、Logo/标签、图案、纹理、材质、配件数量是否一致。
18. 物理接触：手/身体/床/桌面/食材/空间是否与产品真实接触，是否漂浮或穿模。
19. 空间锚点：床头、床垫边缘、桌面、柜体、地面、墙面、身体比例等参照物是否连续。
