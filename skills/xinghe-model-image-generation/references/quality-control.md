# Quality Control

This file is only an optional manual review checklist. It must not trigger automatic regeneration, automatic rejection, or automatic replacement of final images.

## Optional Set Checks

- Delivered count matches the user's request or default count of 8.
- All images are square `1:1` unless the user specified another size.
- All images use the same seamless pure white studio background, not colored backgrounds or lifestyle scenes.
- Image 1 is a full-body model identity reference unless the user requested another first image.
- Images 2 through 8 preserve the same adult Chinese model identity, body type, skin tone, hairstyle, outfit logic, and lighting family from image 1 unless the user requested another ethnicity/nationality.
- Product-to-body scale follows provided size data when available; when absent, it stays within category-normal adult visual proportions and does not imply exact measurements.
- Model facial mood is sunny, positive, approachable, and naturally warm across the set unless the user requested another mood.
- Image roles fit the product category. Handheld goods should include hand scale, detail, presentation, and face-adjacent shots; apparel should include fit, side/back, detail, and movement; shoes/bags/accessories should use their specific wearing/carrying logic.
- The set has meaningful variation in crop, angle, pose, lighting, model styling, and product interaction.
- At least three subject scales appear in the default 8-image set: wider/full, half-body, and close-up/detail.
- No image adds unsupported text, price, sale badge, fake certification, review, rating, medical effect, or unprovided product claim.

## Optional Per-Image Checks

- Product identity remains consistent with the uploaded reference: silhouette, color, material, print/logo/nameplate placement, structure, and relative proportions.
- Visible logos, labels, buttons, screens, or small-text areas remain in plausible positions and do not turn into invented claims, specs, capacity, certification, or random promotional text.
- Product contact with hand/body/clothing is believable; no floating product, impossible grip, wrong scale, contradictory shadow, or broken occlusion.
- No exact size, model height, garment length, capacity, package count, or dimensions are invented unless provided by the user or visibly readable.
- Model looks like a real adult person with natural skin texture, plausible hands, correct fingers, realistic joints, sunny positive natural expression, and believable posture.
- Skin is not over-smoothed, waxy, plastic, or doll-like.
- Background is clean pure white, without gray/beige/pink drift, room details, furniture, plants, windows, street elements, outdoor scenery, or lifestyle clutter.
- If the model's face/body appears, it remains recognizably the same adult Chinese model from the first full-body reference image unless the user requested otherwise.
- Product remains commercially visible and not hidden by pose, hair, hand, blur, crop, or shadow.
- No random accessories or alternative SKU details are introduced.

## Optional Delivery Notes

Mention only relevant issues briefly:

- background drifted away from pure white;
- model identity, hairstyle, or expression drifted;
- hands/fingers or product contact look unnatural;
- product scale looks visually too large or too small;
- logo/label/detail is unclear or text-like but not reliably readable;
- product shape, lid, strap, sole, hardware, fabric, or other key structure changed.

## Review Handling

If potential issues are noticed after generation, mention them briefly as optional review items or items needing confirmation. Do not automatically regenerate.

Only call the generation tools again when the user explicitly asks to regenerate, redo, re-create, fix, or replace a specific image or the full set. When regenerating, change only the requested scope.
