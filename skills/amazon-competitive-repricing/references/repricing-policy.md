# 调价规则

## 1. 状态所有权与调价路由

`$amazon-inventory-clearance` 是“紧急清退、主动清货、停补观察、健康维持、待补货”及建议清货数量的唯一正式来源。调价 Skill 只消费该结论，不根据库龄字段重新判定清货状态。竞品数据不参与状态判断。

先按最新库龄表做保守风险拦截。任一情况存在但没有正式清货结论时，返回 `CLEARANCE_REVIEW_REQUIRED`，停止竞品分析和可执行降价：

- 91 天以上库存；
- 待收 AIS 数量或预计库龄附加费；
- Amazon 标记的超量库存；
- 供给天数超过 90 天；
- 有可售库存但近 60 天零销量。

正式清货结论按下列方式映射：

1. `主动清货`且建议清货数量大于 0 → `ACTIVE_CLEARANCE`。
2. `紧急清退`且建议清货数量大于 0 → `URGENT_EXIT`。
3. `紧急清退`但建议清货数量为 0 → `INVENTORY_EXIT_ONLY`；只提示不可售、搁浅、移除或处置，不降低正常可售库存售价。
4. `停补观察` → `OBSERVE`。
5. `健康维持` → `HEALTHY_HOLD`。
6. `待补货` → 近 30 天有销量且存在后台低库存信号时进入 `LOW_STOCK_PROTECTION`，否则保持价格。

未命中潜在清货风险的 SKU 可直接按调价专属状态处理：

1. `NO_SELLABLE_INVENTORY`：可售为 0，不调价。
2. `LOW_STOCK_PROTECTION`：近 30 天有销量，且库存健康字段显示低库存，或可售加有效在途低于最低库存水平。
3. `OBSERVE`：Low traffic 或近 30 天 Sessions 小于 30。
4. `HEALTHY_HOLD`：其余情况。

清货结论的 SKU、ASIN 和库龄快照日必须与调价输入一致；低置信度、来源缺失或状态与数量不完整时只给暂定价。不可售和搁浅数量始终单独输出。

若有可靠精确库龄，110–115 天作为课程经营预警；只有 91–180 天分桶时，不得虚构到货日期或精确天数。

## 2. 成本与亏损底线

同时计算两套底线。设：

- `L`：美元落地成本；
- `r`：佣金率；
- `Fc`：精确 FBA 配送费；
- `Fo`：仓储、退货准备、未来广告和其他单件可变费用之和；
- `a`：允许亏损占落地成本比例。

```text
现金底线(a) = [L × (1 - a) + Fc] ÷ (1 - r)
经营保本线(a) = [L × (1 - a) + Fc + Fo] ÷ (1 - r)
```

- 正常保本：`a = 0`
- 主动清货：`a = 0.15`
- 紧急清退：`a = 0.30`

底线向上取整到美分。仓储、退货准备、广告和其他变动成本四项完整时使用经营保本线；否则可用现金底线，但必须标记“经营利润待确认”。建议价不得低于当前状态对应的允许底线。
超过 30% 亏损必须单独列案并再次取得用户明确确认。

## 3. 竞品认定

只用 Amazon StyleSnap 原主图搜款。搜索卡片只是候选，必须打开精确子变体，并分别保存搜索截图、详情页链接、变体和履约证据。

- A：底层产品本体、固定结构、材质、尺寸和关键功能一致；
- B：高度相似，但底层本体或结构存在明确差异；
- C：只有风格或使用场景相近。

Ita bag 等展示包判断时，忽略展示窗内徽章、娃娃、插板内容、可拆挂件、珍珠链、可拆肩带、颜色和拍摄角度；重点比较包体版型、固定车线、透明窗、拉链/侧袋、肩带连接和材质。

用户确认优先级最高：

- 用户勾选 B 级竞品的“当做 A 级竞品”后，仅对应 `Seller SKU + 竞品 ASIN` 的有效等级变为 `A / USER_CONFIRMED`；原始 B 级、差异和截图永久保留；
- 暂时无法排除同款的候选按 `A / TEMP_A` 参与，但标记中等置信度；
- 只有底层本体或结构确认不同才降为 B；
- 商品发生实质变化时才重新分级。

`price_role` 与等级分开：

- `PRIMARY`：正常在售的主要市场锚点；
- `LOWER_BOUND`：可信同款，但可能在清仓或明显低价，只用于紧急下界；
- `REFERENCE`：只验证价格带；
- `EXCLUDED`：缺货、错误变体或字段冲突。

正常、健康、观察和主动清货优先使用 A/FBA/PRIMARY 中位价；紧急清退使用最低可信 A/FBA（包括 LOWER_BOUND）。仅有外观 A 级但精确变体或履约未确认时，不得正式跟价。

## 4. 履约和配送分层

A 级 FBA/Prime 始终优先。只有 A 级 FBM 时，本店为 FBA 的情况下直接按竞品承诺配送天数保留溢价；即使 `own_delivery_days` 为空也必须计算，不能错误归零：

- FBA/Prime 到手价取页面当前显示售价，不另行扣减同行 Coupon；
- FBM 到手价取页面当前显示售价加运费，不另行扣减同行 Coupon；
- 不计算美国销售税；卖家精灵与 Amazon 详情页冲突时，以详情页当前履约和价格为准。

- 0–3 天：`$0`
- 4–7 天：`$1`
- 8–14 天：`$2`
- 超过 14 天或中国直发：`$3`

FBM 参考价 = 同行有效到手价 + 配送溢价。
配送日期不明、无法下单或履约证据缺失时只作弱参考，不生成正式配送溢价；明确中国直发可按 `$3` 处理。

Amazon 没有公开固定的 FBA 溢价公式；上述分层是用户确认的经营默认值。

单次运行可以设置 `no_raise_this_run=true`。此时任何高于当前有效售价的结果都改为维持当前价，并保留被拦截的原建议价用于审计；该开关不得持久化为长期禁涨规则。

## 5. 调价动作

### 健康与观察

- `HEALTHY_HOLD`：已确认 A 级 FBA 到手价低于本店时，建议与 PRIMARY 中位价持平；竞品不低时维持当前价。
- `OBSERVE`：同样执行 A 级 FBA 更低即持平；库存状态仍保持观察，不把零订单简单归因为价格。
- 若已进入主动或紧急清货，库存风险可覆盖低流量阻断，但必须注明“尚未证明价格是主因”。

### 低库存保护

- 首轮涨 2%，7 天内最高涨 3%。
- 有 A/FBA 时不得超过其 PRIMARY 中位价 3%。
- A/FBA 已低于本店当前价时，跟价优先，不执行涨价。
- 无 A/FBA 时只给暂定涨价。
- 近 30 天没有销量时不使用涨价保护。

### 主动清货

- A/FBA/PRIMARY 目标价：中位有效到手价低 1%，但低价金额最多 `$0.30`。
- 通过清货结论、成本与费用门禁后可一次回到目标价，不再使用“高于锚点 5%”或 Sessions 作为额外降价门槛。
- 当前价已低于目标区间时停止继续降价。
- 没有 A 级锚点时不再按本店当前价猜测降幅，只输出阻断和待搜图/待确认。
- 观察 7 天；流量弱时延长到 14 天。

### 紧急清退

- 使用最低可信 A/FBA 低 2%作为目标，但低价金额最多 `$0.50`。
- 没有 A 级锚点时不按本店价格猜测降幅。
- 每 3–4 天复核，并比较 Outlet、移除、外部销售、FBA Liquidations、弃置或捐赠的净回收。
- 市场目标低于紧急底线时，不穿透底线；输出“市场无法覆盖底线，转退出渠道比较”。

所有跟价与低价结果直接按规则取整到美分，不为了 `.49` 或 `.99` 尾数突破跟价幅度或亏损底线。

## 6. 以后是否可进货

调价报告只判断采购经济性，不计算补货数量：

- `可按当前成本进货`：状态为健康、正常或满足条件的低库存保护，且目标/维持价覆盖采购、头程和准确 Amazon 费用；
- `暂不进货`：主动清货、紧急清退、停补观察、无可售库存，或当前成本超过目标价下的最大可接受采购成本；
- `数据不足`：缺成本、准确费用、汇率、正式价格或有效 A 级竞品。

```text
最高可接受采购成本CNY
= [目标价 × (1 - 佣金率) - 固定单件费用] × 保守汇率 - 头程
```

结果最低显示 0；头程缺失时用 ¥10。该字段只给下次采购议价参考，不得据此自动采购。

## 7. Price Discount 与价格字段

默认直接修改标准售价。若 Sale Price 正在生效，先在预览中清除 Sale Price 和日期，再设置标准售价。

Price Discount 仅作为备选，必须同时满足：

- 参考价已验证；
- SKU 合格；
- 创建页费用已读取；
- 承诺数量不超过清货 Skill 输出的建议清货量和可售数量；缺少正数清货量时不得提供 Price Discount 方案；
- 不与 Sale Price、Coupon 或其他折扣叠加；
- 用户在看到完整预览后再次明确确认。

主动清货使用 7–14 天；紧急清退使用 3–7 天。
不得虚构 List Price，不承诺一定显示划线价。

## 8. 观察与停止条件

- A 级竞品每日 10:00 轻量复查；B 级周一复查；C 级每月复查；
- 周一全量生成一份清货与调价综合表；周四只有关键变化时生成一份变化表；
- 常规调价决策：每 7 天；
- 低流量：最多观察 14 天或达到约 30 Sessions；
- 紧急清退：每 3–4 天；
- 同一 SKU 在一个观察周期内只改变一个核心价格变量。

任一情况停止继续降价：

- 已达到对应亏损底线；
- 已低于市场目标区间；
- 有流量但问题明显来自错误变体、配送、评价、图片或 Listing；
- 降价后转化没有改善且退出渠道净回收更高；
- 清货 Skill 基于新库龄表更新后不再属于清货状态。
