# 品牌官网分析流程

## 快速扫描

默认抓取首页、产品/功能页和价格页，提取：价值主张、目标人群、核心产品、定价、CTA、客户证据、内容主题和可见搜索信号。

## 深度分析

用户明确要求或竞品不超过3个时，增加：关于我们、客户案例、评论、集成、博客、更新日志、技术栈、关键词和外链数据。

## 工具策略

- 优先使用当前可用的网页搜索、浏览器和页面读取能力。
- Firecrawl、DataForSEO存在时可增强抓取和SEO量化；不存在时不得阻塞任务，也不得伪造指标。
- SEO指标缺失时，使用“未采集”并保留定位、产品、定价和内容分析。

## 输出重点

1. 品牌定位与信息架构。
2. 产品、功能和差异点。
3. 定价与转化路径。
4. 客户、案例和社会证明。
5. 内容与搜索策略信号。
6. 真实优势、弱点、机会和威胁。
7. 用户提供自有产品时才做直接优劣比较。

保存首页、价格、产品、评论和SEO数据原文；注明抓取日期和无法验证的主张。
