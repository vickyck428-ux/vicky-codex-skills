# 输入合同

## 目录

1. 项目参数
2. 方法输入
3. 供应链和利润
4. 文件验收

## 1. 项目参数

必需：目标站点、类目范围、价格带、经营模式、首批损失上限。默认 Amazon US、广义时尚女包、`$19.99–49.99`。

## 2. 方法输入

### 商品库

至少包含 ASIN、标题、类目、上架时间、父子体、销量、售价、评论、履约、卖家国家和发货地。建议增加尺寸重量、自然/广告词、历史价格库存和历史 FBA/FBM。

### 关键词库

至少包含关键词、搜索量、趋势、CPC、转化率、售价、SPR/CPR、标题密度、Top 3 点击/购买份额、平均评论和类目。

### ABA 历史

至少包含站点、周、关键词、搜索频率排名、点击份额、购买份额和主要商品。建议连续 8–12 周；季节判断优先一年。

### 市场调研四表

每个重点市场提供近 30 天竞品表、近 12 个月竞品月表、头部 ASIN 关键词反查、核心关键词转化率。

### 多平台与社媒

提供链接或截图、国家、日期、销量/互动、发货地、是否广告和购买意图。公开信息可由 Codex 收集；登录后字段由用户导出。

### 同行店铺

提供 3–5 个目标 Amazon Storefront；没有时可先给 5–10 个代表 ASIN 反查卖家。

## 3. 供应链和利润

候选进入产品闸门后提供：1688 链接、采购价、MOQ、颜色、尺寸、重量、箱规、定制、打样、生产和运输时间；以及佣金、FBA 费、头程、包装、退货和促销假设。

成本或利润缺失时只能输出 `暂定补数据`，不能输出采购结论。

## 4. 文件验收

运行：

`python3 scripts/input_validator.py <目录> --json`

检查文件类型、方法映射、字段、日期、站点提示和缺口。库存、成本、销量未知不得填 0。
