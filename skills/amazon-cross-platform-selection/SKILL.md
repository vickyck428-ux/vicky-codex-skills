# Amazon 多平台选品

只使用多平台选品方法。不要调用或混入其他选品 Skill。

## 收集输入

优先获取：

- 目标 Amazon 站点；
- 来源平台、国家和商品链接或截图；
- 来源平台核心关键词；
- 来源商品销量、评论、收藏、排名或互动数据；
- 来源商品发货地和配送方式；
- Amazon 搜索结果、同款和近似替代品；
- 采购价、售价、尺寸、重量和可能的知识产权风险。

如果用户只提供商品图片，先识别产品，再让用户确认名称和目标站点。

## 强制市场匹配

只在同一国家或同一消费市场内直接迁移信号，例如：

- 美国 Amazon ↔ 美国 eBay/Walmart/Etsy/TikTok Shop；
- 澳大利亚 Amazon ↔ 澳大利亚 eBay；
- 日本 Amazon ↔ 日本本土平台。

跨文化或跨国家信号标记为 `NEEDS LOCAL VALIDATION`，不要直接判定需求成立。

## 执行流程

### 1. 确认来源平台确实卖得好

按平台解释数据：

- eBay：检查详情页实际 sold 数量，不把 watch/favorite 当销量；
- Etsy：区分商品评论和店铺评论；
- 不显示销量的平台：综合评论、排名、互动、广告持续时间和多个卖家供给；
- 区分本地仓、本地配送和中国直发。

只凭一个广告位或一个视频不能证明需求。

### 2. 找出核心卖点

说明消费者为什么购买该款式。允许后续改款，但必须保留核心卖点。不要把外观差异误当作需求本身。

### 3. 反查 Amazon 供给

同时使用：

- 核心关键词搜索；
- 类目榜单；
- 竞品推荐区；
- 图片或相似商品搜索；
- 变体和子体检查。

分别统计：

- 精确同款；
- 近似替代品；
- 本土 FBA；
- 本土 FBM；
- 跨境远程 FBM。

### 4. 判断机会

优先级从高到低：

1. 来源平台需求明确，Amazon 无同款；
2. Amazon 只有远程 FBM或弱供给；
3. Amazon 有少量同款但销量、Listing 或配送很弱；
4. Amazon 已有成熟 FBA 和大量同款：通常淘汰。

### 5. 验证可执行性

检查：

- 采购和定制能力；
- 毛利率和绝对利润；
- 广告 CPC 和转化率；
- 尺寸、重量和物流；
- 季节性；
- 商标、版权、外观和实用专利；
- 可执行的差异化。

## 输出结论

返回：

1. `可迁移 / 小批测试 / 继续观察 / 不建议迁移`；
2. 来源平台需求证据；
3. 同市场匹配结果；
4. Amazon 同款、替代品和履约供给；
5. 核心卖点；
6. 利润、广告和物流可行性；
7. 侵权风险；
8. 建议的产品规格和测试数量；
9. 缺失数据。

不要因为“其他平台卖得好”就自动判定 Amazon 可做。

## 精铺女包执行协议

对每个候选生成“包型 × 材质 × 功能 × 场景 × 风格”的产品签名，并记录来源国家、发货地、配送方式和证据日期。

强制执行：

1. 需求至少由可核实销量，或两个以上独立信号支持；收藏、广告位、单条病毒视频不能单独通过。
2. 单独判断平台人群、价格、质量、定制和履约是否能迁移。Etsy 手工/定制溢价不得直接套用到量产 Amazon 商品。
3. Amazon 反查必须覆盖同义词、图片、榜单、推荐区和隐藏变体，并分开统计精确同款、替代品、本土 FBA、本土 FBM 和远程 FBM。
4. 计算 `预计可售日期 = 找货 + 打样 + 生产 + 预处理 + 运输 + 上架`，与机会窗口共同判断；赶不上窗口即降级或淘汰。
5. 输出来源证据、核心购买原因、Amazon 供给、可保留卖点、可执行差异、时间窗口、缺口和状态。
