# Amazon 社交媒体选品

只使用社交媒体选品方法。不要调用或混入其他选品 Skill。

## 收集输入

优先获取：

- 目标 Amazon 站点和目标国家；
- 视频、帖子、广告或趋势页面链接/截图；
- 发布时间、创作者和创作者国家；
- 播放、点赞、评论、分享、收藏和 CTR；
- 同类独立视频数量与发布时间；
- 评论区购买意图；
- 产品图片、名称、功能和核心卖点；
- Amazon 同款搜索结果；
- 采购价、预计售价、尺寸、重量和风险。

数据缺失时保留原链接并标记 `NEEDS DATA`。

## 判断信号强度

### 强信号

- 多个独立创作者连续发布；
- 多个视频分别获得高互动；
- 趋势持续而非单日尖峰；
- 评论区反复询问购买渠道；
- 信号来自目标国家；
- Amazon 供给仍少。

### 弱信号

- 只有一个孤立爆款视频；
- 主要流量来自付费广告；
- 互动与播放比例异常；
- 视频很老，Amazon 已经大量跟进；
- 事件、节日或网红个人因素无法复制；
- 评论热闹但没有购买意图。

不要把单条视频的点赞量直接当作商品需求。

## 使用渠道

按实际数据使用：

- TikTok Creative Center：热门广告、热门商品、关键词洞察和趋势；
- Instagram：标签、图片和视频，需要长期刷选；
- Pinterest：趋势、图片、保存和相关内容；
- Reddit：真实需求讨论和痛点；
- YouTube：评测、教程和长周期兴趣；
- X/Twitter：事件和快速传播信号；
- 目标国家的本土社媒。

建立独立选品账号，只点赞和关注产品相关内容，避免娱乐内容污染推荐。

## 识别产品

1. 确认产品用途和核心卖点；
2. 区分新产品、旧产品新玩法和纯内容道具；
3. 找到可采购或可定制的实际规格；
4. 排除影视角色、品牌元素和明显侵权设计。

## 验证 Amazon 机会

搜索：

- 精确同款；
- 近似替代品；
- 变体中的隐藏同款；
- 本土 FBA 和远程 FBM；
- 上架时间和供应增长。

检查：

- 利润和物流；
- 广告是否便宜或可能无需广告；
- 评论依赖；
- 季节、事件和文化适配；
- 专利与合规。

## 分层决策

- **小批测试**：多个独立强信号、Amazon 供给少、采购和试错成本低；
- **完整分析后测试**：已有市场数据和同款，需要计算广告、利润和竞争；
- **监控**：信号早但样本少，或无法确认需求持续；
- **淘汰**：窗口已过、同款拥挤、侵权或利润不成立。

## 输出结论

返回：

1. 来源平台和证据日期；
2. 产品与核心卖点；
3. 信号强度和独立样本数；
4. 目标国家匹配；
5. Amazon 同款与供给；
6. 利润、广告、物流和风险；
7. `小批测试 / 完整分析 / 监控 / 淘汰`；
8. 建议测试数量、监控指标和复查时间。

## 精铺女包执行协议

将每条证据保存创作者、账号国家、发布时间、是否广告、互动和购买意图，并归一到产品签名。相同商家、搬运、联盟批量素材不计为独立创作者。

强制执行：

1. 建立最早内容、首次扩散、多创作者进入、Amazon 供给进入四段时间线。
2. 单独统计询价、求链接、尺寸、容量、颜色等购买意图，不把娱乐评论和点赞直接当需求。
3. 自然内容检查独立创作者；广告内容检查多素材、持续投放时间和落地页，不允许单条病毒内容通过。
4. 计算预计可售日，并按刚出现、早期扩散、快速增长、成熟、衰退判断入仓窗口。
5. 输出独立创作者数、购买意图样本、目标国家匹配、时间线、Amazon 供给、预计可售日、缺口和状态。
