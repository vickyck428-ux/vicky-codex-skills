## 通用采集原则

先明确国家/地区、语言、平台和商品层级。优先使用商品详情页、平台公开评论、问答和公开社区讨论。记录链接、日期、SKU、评分与原话；无法访问全文时，不把搜索摘要当成完整证据。

采样至少覆盖：

- 1–2星：故障、退货、预期落差和严重问题。
- 3星：真实权衡、“可以但……”和改进机会。
- 4星：整体认可下的隐藏顾虑，适合发现竞品突破口。
- 5星：购买理由、惊喜点、复购理由和证明素材方向。
- 问答/客服：购买前顾虑、规格不清、使用门槛和高频误解。

不要用评论数量代替独立证据数。平台合并展示、跨站转载和同文案重复评论需要去重。

## 跨境平台

### Amazon

- 研究评论、评分分布、变体、Customer Questions、退货/频繁退货提示以及竞品页面表达。
- 分开统计不同站点、ASIN和变体；不要把父体评分直接当成单一SKU反馈。
- 检索示例：`site:amazon.com product keyword review`、`product keyword stopped working`、`product keyword returned because`。

### TikTok Shop

- 研究公开商品评论、达人视频评论区、购买前问题和实际演示反馈。
- 区分内容吸引力与实际产品体验；达人口播不能视作买家证据。

### Shopify / 独立站

- 研究站内评价、FAQ、退换货政策和第三方评价站。
- 品牌自有评价可能经过筛选，需与 Reddit、YouTube、Trustpilot 等外部来源交叉验证。

### 其他公开来源

- Walmart、Etsy、eBay、Target 等按商品类型选用。
- 同一品牌跨平台评论可对照，但必须保留平台与市场差异。

## 国内平台

### 淘宝 / 天猫

- 研究评价、追评、问大家、不同规格反馈、买家秀和店铺客服高频问题。
- 区分商品问题、商家服务与物流体验；关注追评揭示的耐用性变化。

### 京东

- 研究评价、追评、问答、晒单和不同型号反馈。
- 自营物流体验与商品质量分开归因。

### 拼多多

- 关注低价预期、实物差异、规格误解、包装与耐用性。
- 价格敏感结论不得直接外推到其他平台人群。

### 抖音电商

- 研究商品评论、直播/短视频评论区和售前问题。
- 将冲动购买触发与长期使用反馈分开分析。

### 小红书

- 用于发现使用场景、种草动机、审美语言和避坑点。
- 商业合作内容、品牌投放和真实消费者反馈分开标注；收藏/点赞不能替代购买证据。

## 社区与社交平台

- Reddit、YouTube、论坛和垂直社群适合获取长文本体验、替代品和失败过程。
- 搜索组合：`品类 + worth it / problem / returned / alternative / review`，或中文的“踩雷、退货、避坑、值不值、替代、用了多久”。
- 社区用户可能偏专业、偏激或偏小众，不能直接代表平台总体买家。

## 来源权重

| 来源 | 主要价值 | 主要偏差 |
|---|---|---|
| 第一方订单/退货/客服数据 | 高，可对应真实交易 | 只代表单一品牌和现有买家 |
| 平台已购评论 | 中高，贴近使用体验 | 极端评价、激励评价和合并变体 |
| 平台问答 | 中高，适合购买顾虑 | 提问者不一定购买 |
| 独立社区长帖 | 中高，情境丰富 | 人群偏差和强意见偏差 |
| 社交评论区 | 中，适合语言与即时反应 | 信息短、身份与购买状态难核验 |
| 达人/测评内容 | 中，适合发现比较维度 | 商业合作与内容偏好 |
| 搜索摘要 | 低，只作为线索 | 缺少上下文，可能过期或截断 |
