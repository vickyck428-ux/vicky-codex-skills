# 商品页分析流程

## 目录

- 采集清单
- 分析顺序
- 数量策略
- 单位价格
- 评论与视觉
- 受限报告

## 采集清单

对每个当前SKU记录：

| 分组 | 字段 |
|---|---|
| 身份 | 平台、商品ID、标题、品牌、类目、卖家、店铺类型 |
| 报价 | 币种、标价、划线价、活动价、券、会员价、参考到手价、结算价说明 |
| SKU | 当前变体、全部可见变体、颜色/尺寸/净含量/数量、库存状态 |
| 市场 | 销量、评分、评论数、榜单、收藏/问答等公开信号 |
| 履约 | 发货方、销售方、配送时效、运费、退换和保障 |
| 内容 | 标题、五点/卖点、主图、图集、视频、详情/A+模块 |
| 评价 | 好评、差评、追评、近期评价的主题和样本量 |
| 归因 | UTM、联盟、广告素材、点击、渠道等追踪参数 |

页面未显示的字段写“未获取”；动态字段必须记录时间、地区和当前SKU。

## 分析顺序

1. **确认商品身份**：消除链接跳转、父子SKU和地区站点歧义。
2. **拆解定位**：提炼目标人群、核心任务、价格带和品牌承诺。
3. **分析Offer**：区分各类价格、赠品、满减、订阅、套装和限购，计算可验证的单位价格。
4. **分析SKU**：识别引流款、主推款、升级款、量贩款及规格间的解释成本。
5. **分析标题**：区分品牌词、品类词、属性词、场景词、规格词、礼赠词和重复词。
6. **分析视觉**：按缩略图/详情顺序描述每屏任务，检查信息层级、证据强度和SKU一致性。
7. **分析评价**：归纳购买动机、满意点、抱怨、退货原因、未满足需求和可验证的文案机会。
8. **回答买家顾虑**：列出购买前最可能阻碍转化的问题，以及竞品是否提供证据。
9. **形成策略**：区分“可借鉴”“可攻击”“风险”和“可超越方案”。

## 数量策略

- 1–3个链接：完整抓取并分别分析。
- 4–10个链接：先统一抓取标题、当前价格、规格、评分、主图和核心卖点；再对差异最大的3个做视觉与评论深挖。
- 超过10个：按品类、价格带、目标人群和商品相关性筛选5个；报告筛选规则。

## 单位价格

- 固体：优先换算每100g；大包装可补充每kg。
- 液体：优先每100ml；大包装可补充每L。
- 计件商品：每件/每套；多包装同时给出单件价格。
- 不同计量维度不得强行比较。含赠品、订阅折扣或不确定优惠时，分别展示基础单价和条件价。
- 只对明确适用于当前SKU的价格和规格计算；公式写入报告。

## 评论与视觉

- 评论至少区分正向、负向、追评、近期四组；记录实际样本数，不以少量评论代表全部用户。
- 优先提取重复出现的主题；代表性原话只做短摘录并隐藏用户名。
- 下载可公开访问的主图和详情图，逐张检查：点击逻辑、卖点、场景、规格、证明、促销、可读性、过期日期、合规风险。
- 图片展示其他SKU时必须标注，避免把大号、不同颜色或套装证据误认为当前SKU。

## 受限报告

当登录、地区、验证码或动态渲染阻止完整读取时：

1. 保留链接解析、搜索摘要、公开元数据、可见图片和已确认字段。
2. 将结论按“已确认事实”“明确推断”“未获取”分组。
3. 列出缺失字段及影响，例如“无评价数据，不能判断用户痛点”。
4. 请求用户补充当前SKU顶部信息、SKU面板、评论页和详情长图，或导出页面/PDF。
