# FBM 第一轮筛选

读取商品表，按固定条件筛选，并导出一个新的结果工作簿。

## 工作流

1. 先确认输入文件路径。
2. 优先读取主数据表；如用户未指定工作表，默认选第一张非“失败页”工作表。
3. 按以下固定条件筛选：
   - `评论数量 < 50`
   - `卖家名称 != Amazon`
   - `卖家所处国家 = 中国`
   - `配送方式 = FBM`
   - `是否有卖家精灵类目排名 = 是`
   - `上架时间天数 <= 200`
4. 输出一个新的 `.xlsx`：
   - `筛选结果`：保留原表全部字段，仅保留命中行
   - `筛选说明`：记录源文件、源工作表、命中数量、筛选条件、各单项条件命中数
5. 即使命中数为 `0`，也照样导出结果文件，并明确写出 `0` 条。

## 字段约定

默认使用以下列名：

- `评论数量`
- `卖家名称`
- `卖家所处国家`
- `配送方式`
- `是否有卖家精灵类目排名`
- `上架时间天数`

如果缺列，先明确报错缺少哪些列，不要静默降级。

## 执行

优先直接运行脚本：

```bash
python3 scripts/filter_fbm_first_round.py --input /path/to/input.xlsx --output /path/to/output.xlsx
```

如果当前 `python3` 缺少 `pandas` 或 `openpyxl`，改用带表格依赖的内置 Python 运行环境。

可选参数：

- `--sheet SHEET_NAME`：指定工作表

## 输出要求

- 保留原始字段顺序
- 不改动源文件
- 结果文件名默认可用 `原文件名_fbm_first_round.xlsx`
- 回复时直接给结果结论和结果文件路径

- `scripts/filter_fbm_first_round.py`：执行筛选并生成结果工作簿
