# 竞品监控规则

## 到手价

```text
同行到手价 = 售价 - 同行 Coupon 折现金额 + 运费
```

百分比变化以旧到手价为分母。旧价为 0 或缺失时只做字段缺失检查，不计算百分比。

## 置信度

- 高：详情页精确子变体已确认、字段完整、无冲突、ZIP 为 `75201`。
- 中：核心价格、履约和配送字段完整，但存在非关键字段缺失。
- 低：变体未确认、价格/履约/配送关键字段缺失，或多个来源冲突。

低置信度仍可记录异常，但建议动作固定为“人工复核，不同步价格”。

## 重要异常二次复核

价格、Coupon、履约、缺货或配送异常第一次在 `75201` 出现时，标记需要用 `10001` 和 `90001` 复核。二次 ZIP 仅用于验证，不改变主环境基线。

## 本店动作边界

- 允许：保存映射、生成 Excel、提醒、给出人工核价建议。
- 禁止：自动调价、创建促销、调整广告、修改 Listing。
- 永久禁止：本店 Coupon 推荐、创建或执行。

## FBA 转仓风险

- 选品阶段以 `candidate_id` 为主体，不要求 Seller SKU；建 SKU 后快照同时携带 `candidate_id + own_sku`，历史按 candidate lineage 接续。

- 高：当前已 FBA；同一 ASIN 历史出现过 FBA；同卖家同父体/同系列已有 FBA；近 90 天至少两次 FBM→FBA；或当前至少两个 ASIN 为 FBA。
- 中：同一卖家有其他历史 FBA；或配送至少缩短 3 天且同时出现评论增长、Sponsored 新增或库存恢复之一。
- 低：没有上述证据。第三方预估 FBA 费用、卖家地址、单次库存或单次配送变化不得单独提高风险。
- 待复核：履约为 `UNKNOWN` 或数据冲突。
- 缺稳定 Seller ID 时风险可显示，但状态固定为 `PROVISIONAL`；同名但稳定 Seller ID 不同的卖家必须分开。
- 高风险只输出“建议缩量试单、人工确认保守量”；不得自动修改补货/订货数量。

监控频率覆盖原 A/B/C 复查节奏：高风险每日，中风险每周两次，低风险每周一次，待复核尽快人工补证。生命周期从进入选品候选池开始，覆盖下单前 24–48 小时、采购在途和本店库存售完/停止经营。

确认 FBM→FBA 后，只路由调价复核和补货复算。清货路由固定为否，除非本店库存另行通过超量、滞销或库龄门禁。

## 搜图与人工确认

- 没有同款映射时，只把本店原主图上传 Amazon StyleSnap；结果明显无关时仅在本地免费裁剪后重搜。
- 禁止关键词搜款、付费图片搜索 API、图片生成和付费抠图。
- 每个 A/B 候选保存详情页 ASIN、原始等级、判级原因、差异点、截图和证据链接。
- 飞书 B 级行可以提供“当做 A 级竞品”复选框；勾选后下一次每日监控按 A 级复查，但不触发 Amazon 写价。
